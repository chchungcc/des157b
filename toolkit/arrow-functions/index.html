isEven

This function uses the modulo operator to check if a number is even.

Named Function

            function isEven(num){
                if(num%2 == 0){
                    return("this number is even");
                } 
                else{
                    return("this number is not even");
                }
            }

Function Expression

            const isEven = function(num){
                if(num%2 == 0){
                    return("this number is even");
                } 
                else{
                    return("this number is not even");
                }
            }

Arrow Function

            const isEven = num => {
                if(num%2 == 0){
                    return("this number is even");
                } 
                else{
                    return("this number is not even");
                }
            }
