Usability Results

Observations

  • Users seem to be able to go through the questions and narrative without difficulty
  • Actual statistics were surprising to users, so it would be good to add more visual interest to these elements for emphasis
  • Scrolling elements were intuitive, but would be helpful to add some sort of indicator
  • Overall accessibility and design seem to resonate / work well with users
  • Wording for questions were understandable

Improvements

  • As of usability testing, my project remains largely incomplete. Things that I need to add are:
    • Graphs showing how other users answered for the questions
    • Actual statistics to correct common misperceptions about immigrants and immigration
    • Timeline of immigration history
    • Discussion of the future
  • I also need to improve the overall engagement and visual interest of my project:
    • Adding small decorative graphics
    • Animations on text to emphasize important information
    • Scrolling animations
  • Users seem to be interested or resonated with the project topic and wanted to explore further (wanted to learn more)
  • Based on feedback:
    • Shorten length of text to make it easier to scan across the screen
    • Use error messages instead of alerts
